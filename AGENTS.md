# FrixeP: instruções para agentes de IA

**Este é um projeto que já existe.** Não crie um projeto novo, não pergunte qual stack usar e não use
assistentes de criação/configuração de projeto.

O contexto completo (tecnologia, estrutura, comandos, regras de Git, segurança e especificações de arte) está em
**[CLAUDE.md](CLAUDE.md)**. Leia esse arquivo primeiro; ele é a fonte única de contexto.

Regras essenciais:
- No PowerShell use `npm.cmd` no lugar de `npm`.
- A branch `main` é protegida: trabalhe em branch própria e abra Pull Request. Nunca use `git push --force`.
- Nunca peça, leia ou grave senhas, tokens, chaves ou o conteúdo de `.env`.
